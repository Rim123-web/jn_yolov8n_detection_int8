# FPS definitions

- Engine FPS: `1000 / 89.451038 ms = 11.179300` images/s.
- Transfer-inclusive FPS: `1000 / 94.839536 ms = 10.544126` images/s.
- Latency-derived pipeline FPS: `1000 / 146.395216 ms = 6.830824` images/s.
- Wall-clock pipeline FPS: `192 / 30.984266 s = 6.196693` images/s.

Engine FPS is not labeled application FPS. Warmups and all offline analysis are excluded.
